# Driver — Page Overrides

> Generated: `search.py "field worker delivery task mobile" --design-system --density 5 --motion 3 --page driver`, then curated.
> Kept: mobile-first, specific inline errors, tonal elevation instead of shadows, pill chips. Rejected: native-only effects (haptics, Reanimated).

## Overrides
- **Density:** 5 — large touch targets (≥44px), one task per card, primary status action per stop.
- **Content:** only assigned Transportation work: today's route, current stop, load/handling, status actions, concise cited shift briefing, permitted documents.
- **No** company KPIs, no other drivers' shipments, no module map diagnostics.
- **Stale data:** ETA stale badge must be visible on every affected stop and in the briefing.
